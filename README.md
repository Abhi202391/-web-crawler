# Website Analytics Tool

## Run in VS Code

Open this folder in VS Code, open Terminal, and run:

```bash
python analyze_links.py https://www.python.org/
```

JSON:

```bash
python analyze_links.py https://www.python.org/ --to=json
```

CSV:

```bash
python analyze_links.py https://www.python.org/ --to=csv
```

No external Python packages are required. The project uses only the Python standard library.
